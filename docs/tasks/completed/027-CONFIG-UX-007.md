# CONFIG-UX-007 Dialog and destructive action localization

**State:** COMPLETED
**Plan source:** `docs/tasks/settings-uiux-operation-integration-plan.md`

## Goal

Localize all Settings dialogs and destructive/restart/trust-sensitive confirmation flows.

## Acceptance

- Reset appearance, remove package, repair, language restart, and trust failure dialogs use localized title/body/button strings.
- Dialog titles use `Fcitx5 for Windows Next`.
- Dialog bodies explain what changes and what data is preserved.
- Source/i18n contracts prevent new hard-coded normal Settings dialog strings.
