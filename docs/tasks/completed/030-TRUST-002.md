# TRUST-002 PQC signature envelope parser

**State:** CURRENT
**Plan source:** `docs/tasks/signed-repository-trust-design.md`

## Goal

Parse and validate versioned PQC signature envelopes for repository indexes and package manifests.

## Acceptance

- Parses `index.sig.json` and `manifest.sig.json`.
- Validates `format_version`, `signed_object`, `canonicalization`, `key_id`, `algorithm`, and base64 signature fields.
- Rejects missing required ML-DSA-65 signature.
- Rejects unknown required algorithms.
- Rejects duplicate signatures from the same key.
- Rejects envelopes for the wrong object type.
