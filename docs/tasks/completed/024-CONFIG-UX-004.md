# CONFIG-UX-004 Font picker

**State:** COMPLETED
**Plan source:** `docs/tasks/settings-uiux-operation-integration-plan.md`

## Goal

Provide a real font selection path for candidate rendering instead of relying on manual text entry.

## Acceptance

- User can choose a font with mouse/keyboard.
- Selected font persists to `fonts.candidate.families`.
- Preview updates immediately.
- Reopening Settings shows the selected font.
- CJK and emoji fallback behavior is visible or explained.
