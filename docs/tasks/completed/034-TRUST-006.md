# TRUST-006 Signed repository UI state

**State:** COMPLETED
**Plan source:** `docs/tasks/signed-repository-trust-design.md`

## Goal

Surface signed repository trust states in Settings Add-ons/Updates without implying unsafe online installation is available.

## Acceptance

- No official online plug-ins are displayed without trusted repository metadata.
- Signature, rollback, revoked-key, and missing-key failures are localized.
- Controls and trust messages do not overlap at required DPI/minimum sizes.
