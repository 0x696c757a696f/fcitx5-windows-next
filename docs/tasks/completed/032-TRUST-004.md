# TRUST-004 BLAKE3-default manifest hashes

**State:** COMPLETED
**Plan source:** `docs/tasks/signed-repository-trust-design.md`

## Goal

Make BLAKE3 the required/default payload hash for v2 manifests while keeping SHA-256 as compatibility metadata.

## Acceptance

- v2 manifests require BLAKE3 for every payload entry.
- SHA-256 remains optional compatibility.
- If both BLAKE3 and SHA-256 are present, both must match.
- Corrupted payload fails before activation.
- Old v1 package hash behavior remains covered until migration/removal.
