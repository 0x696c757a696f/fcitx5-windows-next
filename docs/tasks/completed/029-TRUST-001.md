# TRUST-001 PQC keyring parser

**State:** COMPLETED
**Plan source:** `docs/tasks/signed-repository-trust-design.md`

## Goal

Add v2 trusted keyring policy parsing for the future PQC-first repository trust model.

## Acceptance

- Parser accepts `format_version: 2`.
- Parser accepts ML-DSA-65 trusted/revoked keys.
- Parser optionally accepts the selected SLH-DSA recovery key type.
- Parser rejects wrong public-key lengths for supported algorithms.
- Parser rejects duplicate key ids.
- Parser rejects unsupported algorithms required by policy.
- Existing compatibility tests remain green until old RSA paths are explicitly removed.
