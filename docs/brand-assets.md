# Fcitx5 for Windows Next brand assets

The default product and TSF picker icons are original geometric artwork generated from `resources/icons/generate_icons.py`.

- Product/start/config icon: rounded product tile with simplified penguin silhouette.
- TSF picker icon: separate language-neutral micro-penguin glyph for 16/20/24 px; it is not a downscaled detailed master.
- The icons intentionally contain no language characters, flags, engine logos, `F`, `5`, or dynamic input-method state.
- Status variants (`fcitx5-paused.ico`, `fcitx5-error.ico`) reuse the same penguin family with a small badge for explicit/optional shell surfaces.
